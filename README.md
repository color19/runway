# Runway

> Time flies, but I'm the pilot.

从 deadline 倒推，每天告诉你今天的**航速**：照这个速度飞，就能准时落地。

灵感来自 [日有回响 DayEcho](https://riyouhuixiang.com)，在它的思路上做了自己的版本。单个 HTML 文件，打开即用，数据只存在你自己的浏览器里。

## 功能

- **航速**：多个计划项目按截止先后一起倒推，按你每天可投入的时间分配；多做或少做都会自动摊到后面几天
- **计划项目**：模块 + 任务，一次批量加任务（`Reading {1-10}`），按最近两周的真实速度预测完成日
- **一键排进日历**：把未排期的任务沿着每天的航速均匀排开
- **计时器**：给任务或项目计时，实际用时自动记录，并按你的速度调整剩余预计
- **日历**：月 / 周视图，任务池拖拽排期（手机长按或用拖动手柄），右键或双击某天直接新建
- **快速输入**：`明天 14:00 组会`、`周五交论文 2h #标签`、`每周一三五 跑步 到12月1日`、`@项目名`
- **今日概览**：昨天多做 / 少做的分摊、逾期一键处理、连续天数、写给今天的自己
- **数据统计**：趋势、时间分布、热力图、一周节奏、预计 vs 实际
- **回响之书**：每周划掉的事和留言，装订成可以翻页的书
- **导出**：CSV、ICS（导入苹果 / Google 日历）、Markdown 任务清单、JSON 备份与恢复

## 使用

直接用浏览器打开 `index.html`，或者访问 GitHub Pages 上的在线版本。

数据保存在浏览器的 localStorage 里，清除浏览器数据会丢失，记得在「导出与备份」里定期下载备份。

在 Claude 里作为 Artifact 打开时，还会额外启用账户同步，以及「让 Claude 帮我拆任务」和「周回顾」。

## 快捷键

`N` 新建 · `T` 回到今天 · `M` / `W` 月 / 周 · `←` `→` 翻页 · `/` 搜索 · `⌘Z` 撤销

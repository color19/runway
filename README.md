# Runway

对 ADHD 友好的计划工具：从 deadline 倒推，告诉你现在做哪一件。覆盖备考、学习和生活。

线上旧版是一个 claude.ai artifact，这个仓库是把它重建成可长期维护的 app 的起点。第一步只做了一件事：把旧版里最有价值的排程引擎原样搬出来，并用测试证明搬得一模一样。

## 现在有什么

**能用的版本：** https://claude.ai/artifact/S2ciyRbWrBAj86haWpHMhG

- **今天页和项目抽屉**（`app/`）：现在做哪一件、先做 10 分钟或整块计时、接下来两件、今天全部；抽屉按项目列出没排的事，放到今天、挑一天、放回项目。
- **跑道灯**：一盏灯 10 分钟。计时的是实心灯，做完但没计时的按预计时长点成空心灯。今天、最近七天、每个项目都看得到。
- **随手记**：一句话加任务，`#项目` 和 `45m` 会自动识别。
- **数据**：存在页面自己的数据库里，电脑和手机打开同一个链接看到同一份。可以导入旧版备份，也能导出成旧版备份格式，随时退回旧版。
- **排程引擎**（`engine/`）：从旧版原样搬出，并与旧版逐日对照测试。

## 接下来

产品方向见 [PRODUCT.md](PRODUCT.md)：对 ADHD 友好，范围覆盖备考、学习和生活。按顺序：

1. 收工流程，去掉逾期堆。
2. "现在做这个"首屏，接上引擎。
3. 日常事务的数据模型：重复、不打卡、占用可用时间。
4. 错题本。

npm install
npm test

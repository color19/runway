# Runway

从 deadline 倒推的备考计划工具。

线上旧版是一个 claude.ai artifact，这个仓库是把它重建成可长期维护的 app 的起点。第一步只做了一件事：把旧版里最有价值的排程引擎原样搬出来，并用测试证明搬得一模一样。

## 现在有什么

- **排程引擎**（`engine/`）：多个项目共享每天的可用时间，按最早截止优先倒推分配；支持请假日、单日改时长、缓冲天数、按份数计的目标（比如每天投 3 份简历）；给每个项目判断"稳 / 有点赶 / 时间不够 / 会晚"。
- **对照测试**：用 10 月 7 日的真实备份和一份手写样本，在 14 个日期上逐项比对新引擎与旧页面的结果，全部一致。

## 接下来

方向见 [RESEARCH.md](RESEARCH.md)。按顺序：
